## Screens

| 畫面 | 狀態 | 入口與出口 |
|---|---|---|
| 首頁 | 初始、資料可讀、定位／快取進行中、離線、快取失敗 | 啟動即進；出發不等待定位或快取 |
| 附近探索 | 全部、類別多選、零筆、定位成功／失敗 | 首頁出發、結束導引；可搜尋、點資源、開設定 |
| 目的地標示 | 未指定、搜尋中、已指定、無座標、已清除 | 搜尋結果設定旗標；不修改資源選取 |
| 資源連線 | 未選、已選有座標、已選無座標、無有效位置 | 選資源；有座標才連線，無定位的估算明示來源 |
| 店家詳情 | 開啟、未知欄位、送出外部動作、失敗／無橋接 | 點資源／詳細資訊；關閉、遮罩或 Escape 回原畫面 |
| 全螢幕導引 | 自由探索、資源導引、有 GPS、待定位、離線 | START；結束回探索並保留目的地、類別、資源 |
| 搜尋面板 | 空白、查詢中、本機結果、線上結果、零筆、取消／失敗、離線本機 | 點搜尋；選結果關閉面板，目的地獨立儲存 |
| 離線設定 | idle、進行中、完成、部分失敗、不支援 | 探索底部；關閉回原畫面，重試不更動目的地 |
| 方向與距離 | 有定位、無定位、正北基準、有裝置方位、方位不可用 | 選資源開方向；保留文字與明示非步行路線 |

### Transitions
```text
首頁 -> 探索 : 出發
探索 -> 搜尋 -> 目的地標示 : 送出查詢並選擇結果
探索／目的地標示 -> 資源連線＋詳情 : 點資源
詳情 -> 原探索／導引 : 關閉、Escape 或點遮罩
資源模式 -> 自由探索 : 點模式切換；取消資源及連線，不清除目的地
自由探索 -> 資源模式 : 已有資源才可切換；否則提示先選取
探索 -> 全螢幕導引 : START；沒有資源亦可自由探索
全螢幕導引 -> 探索 : 結束或返回；保留搜尋及類別
任意地圖狀態 -> 同狀態離線 : 連線中斷；不清除可讀內容
```

## Flows

### Flow: 出發並選類別（US-1）
1. 開啟 App -> 首頁先呈現，定位與全市資料快取並行開始。
2. 點出發 -> 地圖顯示可用位置；尚無定位明示非目前位置。
3. 點一至多個類別 -> 任一符合者 highlight、其餘降低強度，更新可視範圍的實際筆數。
4. 再點已選類別 -> 取消；零筆顯示零與調整地圖入口，不自行換類別。
5. 點資源卡 -> 地圖定位該點並開詳情。

### Flow: 搜尋目的地並取得資源（US-2）
1. 點搜尋 -> 開可關閉面板、聚焦輸入，提示離線時僅查已下載資料。
2. 明確送出 -> 本機名稱／地址先比對，連線時依既有節流查線上地理編碼，不附 GPS。
3. 選結果 -> 設定獨立旗標、移動地圖；已選資源仍保留，不畫目的地的導航路線。
4. 點資源 -> 中央白卡、遮罩，列真實資料與來源／更新日。
5. 點導航／撥號 -> 沿用裝置協定；無 bridge 或失敗明示並可複製，不宣稱成功。
6. 關閉詳情 -> 回原視角與選取；清除目的地只移除旗標與搜尋名稱。

### Flow: 滿版探索與方位導引（US-3）
1. 可選交通偏好 -> 單選外觀改變，說明仍是直線距離，不變出道路路徑或分鐘數。
2. 選資源或維持自由探索 -> 模式文字對應狀態；切回自由探索取消資源連線。
3. 點 START -> 同一地圖進滿版；資源模式顯示真實距離與正北方位，自由探索顯示周邊狀態。
4. 點資源入口 -> 可看清單／選資源；定位缺失提供重新定位，不顯示假方位。
5. 底圖不可用 -> 保留點位，方向與距離面板可提供文字導引；不保證現場通行。
6. 點結束 -> 回探索，保留目的地、篩選、已選資源；沒有確認頁。

### Flow: 離線與失敗退路（US-1～US-3）
1. 首次連線 -> 自動快取 app shell、全市點位及既有底圖範圍。
2. 查看狀態 -> 只有全部成功才顯示完成；部分失敗列缺漏，可重試。
3. 斷網 -> 保留已下載內容；搜尋只用本機，定位與距離計算不依賴線上地圖。
4. 開店家 -> 仍有來源與更新日；導航／通話依賴外部程式的限制清楚說明。
5. 恢復連線 -> 沿用既有快取重試機制，不重設探索狀態。

### Flow: 設計交接（US-4）
1. 組員讀來源目錄與 screen-map -> 確認六個畫面、排除項與採用的節點。
2. 讀設計及互動規格 -> 依 token、構圖與狀態完成實作，不能只複製截圖的示意內容。
3. 以 390×884 逐畫面擷取 -> 對照原稿與差異表，執行來源／狀態驗收。
4. 列出新增差異 -> 有意義變更先更新設計基準；Ci 審閱前不得把草稿標為已核准。

## Gestures
| 元件 | 操作 | 結果 |
|---|---|---|
| 地圖 | 拖移／雙指縮放 | 調整範圍，更新附近資源；不改真實 GPS |
| 類別／資源卡 | 水平滑動 | 查看完整選項，不造成整頁水平捲動 |
| 資源 | 點擊／Enter | 開詳情與資源選取 |
| 詳情遮罩 | 點擊空白／Escape | 關閉並還原焦點 |
| 頁面／長面板 | 垂直捲動 | 可到達所有內容，不強制拖曳手勢才能退出 |

## Micro-interactions
| 觸發 | 動畫 | 時間 |
|---|---|---|
| 按鈕按下 | 輕微縮放或底色改變 | 100–150ms |
| 面板開啟 | 淡入、小幅位移 | 150–200ms |
| 資源選取 | 標記加亮，平順移至可見範圍 | 遵循減少動態偏好 |
| 快取／定位更新 | 就近文字與 aria-live 更新，不彈阻擋式對話框 | 狀態完成時 |

## Responsive Interactions
手機與桌面同樣提供明確按鈕，不以 hover 或手勢作為唯一入口。鍵盤 Tab 可到所有主要控制；面板開啟後焦點在面板內，關閉回原觸發點。200% 字級及短螢幕可捲動，安全區不遮住底部操作。偏好減少動態時不使用非必要位移或持續脈動。
