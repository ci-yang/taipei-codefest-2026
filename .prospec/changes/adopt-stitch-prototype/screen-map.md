## 原稿未涵蓋的狀態

搜尋空／載入／錯誤、無GPS、定位精度不足、離線、部分快取失敗、無座標、無電話、未知條件、無bridge、關閉焦點還原由既有實作與 interaction-spec 定義。這些狀態有意保留，不能為貼近順利情境截圖而刪除。

## 新畫面與功能界線

首頁、滿版導引、交通偏好列正式記入本 change；目的地／資源連線／詳情是既有流程的視覺更新。交通偏好可選取，但不表示取得道路路由。多站停靠與真正交通路線／估時須另走計畫及資料來源核對，不可把原稿的固定數字當後端契約。

## 後續實作驗收門檻

1. 開工先讀三份規格、六張原 PNG、對應 HTML 文字檔與本表；不能只看首頁或聊天摘要。
2. 使用可操作原型的 token 與結構；來源HTML與原型不一致時先查本表。出現新差異，要在變更中記錄，不能自行換一套主色或版面。
3. 以 **390×884** 取得首頁、探索、目的地、資源連線、詳情、導引截圖，逐張核對地圖360px、搜尋32px上距、類別與卡片橫滑、主操作與交通列順序、詳情遮罩。
4. 補測 320px、430px、短螢幕與文字放大；沒有整頁水平捲動，重要操作不被遮住。
5. 跑 `pnpm test:prototype` 與 `node --test scripts/build-friendly-app.test.mjs`；定位、目的地／資源獨立、離線、未知資料與無bridge退路均要保留。
