# 城市生存雷達：四個亮點原型

## Background
Ci 要求在目前已部署的友善同行 App 上試作四項亮點：Wi-Fi 同心圓、廁所水球倒數、房價含金量與低電量縮圈。既有版本已具 GPS、全市公開資源、本機步行路由、可展開地圖。本輪交付可操作原型供選擇方向，不改正式站或原生 App。

## User Stories
### US-1: 看懂 Wi-Fi 風暴與沙漠 [P0]
作為沒有行動網路的步行者，我想看附近 Wi-Fi 點位的同心圓與疏密，判斷下一步可去哪裡。
**Acceptance Scenarios:**
- WHEN 開啟 Wi-Fi 雷達，THEN 地圖繪製公開點位的同心圓與脈動，呈現附近點位密度和明示半徑的估算覆蓋率。
- WHEN 移動地圖或關閉模式，THEN 統計依畫面中心更新或圖層移除；明示這不是實測訊號，沒有定位時不稱為本人所在區域。
**Independent Test:** 移到密集及稀疏區，核對圓圈與點位資料；減少動態時停止脈動。

### US-2: 用水球看廁所還有多遠 [P0]
作為正在找廁所的步行者，我想選廁所後看估計步數與時間，並按開始倒數。
**Acceptance Scenarios:**
- WHEN 選取廁所且有有效位置與本機道路，THEN 呈現水球圖示、本機路程、估算步數及秒數；開始後水球與秒數同步變化。
- WHEN 暫停、重置或切換廁所，THEN 倒數正確停止或重建，不把倒數歸零當成實際抵達，也不修改原目的地路線。
- WHEN 定位或道路不可用，THEN 顯示原因與重試，試玩座標與加速倒數均清楚標記為展示。
**Independent Test:** 固定公開展示位置選廁所，開始、暫停、恢復、切換與歸零；不能使用手機計步感測器的名稱假稱實測。

### US-3: 看廁所區域的房價趣味指數 [P0]
作為試玩者，我想看到廁所區域住宅交易樣本最高總價換算的每秒房貸成本，理解位置背後的價格差異。
**Acceptance Scenarios:**
- WHEN 選取有行政區及公開資料樣本的廁所，THEN 顯示該批篩選住宅最高總價、來源、樣本期間、貸款假設與每秒試算。
- WHEN 按下我已抵達開始體驗，THEN 金幣動畫與累計試算金額按時間增加，可停止或重置；文案不稱真實收費或真實收益。
- WHEN 行政區或樣本缺少，THEN 顯示待補，不編造價格、不以零元替代；完整公式可展開查看。
**Independent Test:** 以官方篩選列核對一區最高總價與月付換算；啟動與停止累計不影響 GPS 或主路線。

### US-4: 電量低時看到生存縮圈 [P0]
作為低電量步行者，我想看估算可走範圍與圈內充電點，讓尋找充電更直接。
**Acceptance Scenarios:**
- WHEN 可取得電量且低於20%，THEN 啟動步行估算圈、圈外深灰，突出圈內充電資源；20%以上恢復一般地圖。
- WHEN 裝置讀不到電量，THEN 說明不支援並提供標示為試玩的電量滑桿，不假稱真實讀值。
- WHEN 改變試玩電量、耗電假設或位置，THEN 範圍與圈內資源同步重算；無位置或保留電量不足時不顯示錯誤可達承諾。
**Independent Test:** 依序設定20%、19%、8%、5%，核對啟動門檻、圈大小、零半徑與充電篩選。

## Stated Assumptions
- 本輪 standard：同一個前端原型與獨立展示計算，無後端／原生介面變更；維持 story＋design，先供 Ci 審閱，不宣稱正式上線。
- 以 fb10cc3 的 Leaflet／純 JS 原型為本體，延伸 Stitch 紫橘設計。四模式互斥，既有搜尋、導航與返回保留。
- Wi-Fi 示意半徑50m、統計範圍300m；同座標四捨五入至5位去重為點位群，密度0為沙漠、1～2為綠洲、3以上為風暴。覆蓋率為圈聯集抽樣估算，非訊號強度或連線可用率。
- 步長0.7m、每分鐘100步是可見試算條件；不是實際步數、身體忍耐能力或無障礙通行保證。
- 房價區域先以資源地址明載的臺北行政區比對；採官方批次中篩選住宅最高總價，非歷年市場最高。房貸示範：8成、年利率2.5%、30年本息攤還、每月30天；不是銀行報價或廁所估值。
- 電量圈先做步行時間×速度的直線半徑上限：保留5%、假設每小時耗電20個百分點、4km/h；不是實測剩餘續航或依道路可達的等時圈。正式化前需校準與路網可達範圍。
- 提供公開固定位置、18%電量及加速時間的展示入口，明示展示狀態；恢復 GPS 可退出。GPS 不送外部路由。
- 資源位置使用既有公開資料，房價用額外官方公開批次；不編造缺漏、不新增互助／帳號／回報。

## Edge Cases
- 缺GPS：可看地圖中心Wi-Fi，不能假稱本人範圍；廁所與電量需定位或明確試玩。
- 路由失敗或快速選取：取消過時結果，計時不啟動；已選一般目的地道路保留。
- 背景頁面與暫停：依截止時間校準倒數；動畫在背景或減少動態時停播。
- 密集點位：用共用繪圖層與有限動畫，不能每個點位常駐多個DOM動畫。
- 房價缺樣本、無地址、非臺北區域：顯示待補。

## Functional Requirements
- FR-001：四模式切換與可收合雷達面板，手機320px以上可操作。
- FR-002：Wi-Fi 圈聯集估算與密度動畫，資料來源與假設可查看。
- FR-003：獨立廁所本機路程、估算步數、水球計時生命週期。
- FR-004：官方住宅樣本的區域價格對照、可解釋月付與每秒公式、趣味累計。
- FR-005：低於20%門檻、深灰遮罩、圈內充電與誠實電量來源。
- FR-006：展示／實際狀態分明、減少動態、既有地圖與隱私契約不回歸。

## Success Criteria
- SC-001：四項亮點均可從目前 App 進入、操作、退出。
- SC-002：房價每筆可追溯官方批次與篩選規則；Wi-Fi／電量／步數假設在畫面可見。
- SC-003：320、390、768px及短橫向無整頁橫向溢出，按鈕可觸控。
- SC-004：獨立瀏覽器試玩核對四條流程、既有路線與 reduced-motion。
