# Interaction Spec: 城市生存雷達

## Screens
| State | Description | Entry |
|---|---|---|
| Explore | 既有地圖／搜尋／資源 | 開啟App或退出雷達 |
| RadarWiFi | 同心圓＋中心附近密度 | Wi-Fi模式 |
| RadarToilet | 選取廁所、水球與估算倒數 | 倒數模式 |
| RadarGold | 區域樣本價格與趣味累計 | 含金量模式 |
| RadarBattery | 電量狀態、縮圈與充電 | 電量模式或裝置低於20% |
每個狀態保留原目的地路線；切換模式不改使用者目的地。導航／詳細資料沿用原流程。

## Flows
### Wi-Fi風暴
1. 點城市雷達→Wi-Fi；圖層與中心300m統計更新。
2. 拖動地圖→中心統計更新，密集為風暴、稀疏為綠洲／沙漠；不說是訊號測量。
3. 點假設→看50m半徑、去重與估算聯集方法。
4. 關閉→清除額外圖層，回原地圖。

### 廁所倒數
1. 點倒數模式→選附近廁所或地圖廁所點位。
2. 沒GPS→請求定位，或使用有標記的公開展示位置。
3. 本機算路成功→水球、步數、秒數；失敗→原因與重試，不能開始。
4. 開始→以截止時間倒數；暫停→凍結剩餘時間；恢復→續計；重置→恢復初值。
5. 20倍展示→清楚標明加速；歸零只顯示估計時間到，不自動判定抵達。
6. 換廁所→取消前一筆Worker、停止舊倒數並重算。

### 廁所含金量
1. 選廁所→從地址行政區選官方樣本。
2. 有樣本→每秒試算與最高樣本總價；缺區或無樣本→待補。
3. 展開條件→8成、2.5%、30年、30天月與官方批次；非實際費用。
4. 點我已抵達→開始趣味累計；停止／重置→凍結／歸零。不以GPS自動認定室內抵達。

### 生存縮圈
1. 取得可用裝置電量→標記裝置來源；無支援→說明可用手動試玩。
2. 選18%試玩→明示示範，低於20%啟動深灰遮罩；點回裝置→移除模擬。
3. 滑動電量→範圍、估算分鐘與圈內充電同步變化。
4. <=5%→範圍0；>=20%或裝置正在充電→停止警戒。
5. 點充電點→原有詳情／導航；圈只代表試算直線上限，不保證道路可達或插座可用。

## Gestures
地圖拖曳／雙指縮放沿用；模式與動作支援觸控、鍵盤；滑桿支援方向鍵。收合按鈕沿用既有控制，計時仍存在於模組但隱藏時動畫停播。

## Micro-interactions
| Trigger | Animation | Duration |
|---|---|---|
| 按下 | scale .97 | 160ms |
| 模式切換 | opacity＋小位移 | 180ms |
| Wi-Fi | 有限點位的同心圓擴散 | 2.8s循環 |
| 倒數 | 水波位置／透明度，水位隨剩餘比例 | 水波3s，水位每秒更新 |
| 累計 | 單一金幣rotateY | 3s |
| 縮圈 | 圈邊界與遮罩更新 | 180ms |
背景頁面及prefers-reduced-motion停裝飾動畫；數字照真實或明示加速時計算。不得每秒重算道路或全部點位。

## Responsive Interactions
手機以點按為主，桌面hover只作輔助；所有功能無需hover可達。320px與短橫向面板可捲動，展開地圖仍保留退出與收合工具。
