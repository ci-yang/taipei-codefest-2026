# Design Spec：目的地路線與探索控制

> 沿用既有 Stitch 原型與 Ci 本輪明確修改項目，局部擷取及延伸；不重設品牌與首頁內容。2026-11-07。

## Visual Identity
設計判讀：公共資源手機App，以實用地圖為中心；保留淺色、橘色主操作、紫色資源與系統繁中字體。視覺變化低、資訊密度中等、動態少。

| Token | 值 | 用途 |
|---|---|---|
| --color-primary | #3525cd | 資源highlight、鍵盤焦點 |
| --color-action | #ff5e3a | START、目的地道路 |
| --color-background | #f6f8fc | 頁面 |
| --color-surface | #fff | 搜尋與浮動面板 |
| --color-text | #0f172a | 主文案 |
| --color-muted | #64748b | 次文案 |
| --font-body / --font-label | 14px / 12px | 正文／輔助 |
| --space-xs / sm / md / lg | 4 / 8 / 16 / 24px | 間距 |
| --radius-card / pill | 16 / 999px | 卡片／按鈕 |

系統字體沿用既有設定；一般點擊目標至少44px。深色沿用既有token，不另造一套顏色。按下回饋僅短暫transform；尊重減少動態。

## Components
### 搜尋與目的地路線摘要
頂部搜尋列維持原寬度，目的地可清除。路線摘要以估計步行距離＋沿線資源數呈現，補一句「路線兩側250m，非可達保證」。
狀態：預設搜尋；計算中顯示文字；成功顯示距離；無定位／超範圍／失敗顯示原因及重試。pointer未操作不主動畫焦點；Tab保留紫色焦點框；輸入框聚焦仍可見。
道路用action色實線；起終點估計接線為同色虛線；既有資源方向線維持其直線標示，目的地線不因開店家而消失。

### 緊湊探索模式
模式文案占剩餘寬度、START占內容寬；44px最小高度、14px字、16px箭頭，短文案「隨心探索附近資源」／「查看資源方向」。標準字級一行；長店名不放在此列。
狀態：自由／資源模式文案切換；按下輕縮放；disabled不啟動；鍵盤focus-visible；無額外loading或error，錯誤交由現有提示。

### 地圖與浮動面板
搜尋在頂部，定位與展開工具分開放置，觸控目標44px。預設保留地圖＋內容比例，展開後地圖填滿App可用區域；資源面板改浮動、可收合，保留一顆復原鈕。
面板頂部收合鈕＋狀態標籤，內容為既有類別／資源／模式；展開內容限高可捲動。收合以hidden移出焦點序列，不只透明。復原保留資源與類別，不重設行程。
狀態：一般／地圖展開／面板收合；active圖示及aria同步；hover僅精細指標生效；焦點可見。無載入資料時仍可復原，空集合顯示文字。

### TownPass 首頁入口與返回列
沿用TownPass既有首頁、底部導覽、色彩與字體；上方新增一個清楚的「友善同行」入口，與原服務清單導到同一容器。
服務容器頂部保留原生「返回台北通」，網頁loading／error／retry皆可返回。無帳號新增頁面。返回列不被Web內容覆蓋。
狀態：首頁預設、服務載入中、載入成功、失敗重試；標準原生按鈕press/focus/語意，不建立新的視覺系統。

## Responsive Strategy
| 條件 | 行為 |
|---|---|
| 320px～430px | 單欄、緊湊START；內容最小寬0、必要文字可讀；頁面無水平捲動 |
| 768px以上 | 一般頁維持手機內容寬度；地圖展開可用完整viewport，浮層限制閱讀寬度 |
| 手機橫向／短高度 | 地圖工具固定可觸及；面板內容限高可捲動，復原鈕不可藏在面板深處 |
| 大字級 | 可換行／縱向捲動優先，不以裁切換取單行 |
| 鍵盤／減少動態 | 可達的展開復原與Tab焦點；取消非必要transition |

## 修改對照
| Before | After | Why |
|---|---|---|
| 搜尋未操作即3px藍框 | pointer不強制focus，Tab保留 | 移除非操作選取感 |
| START寬111～130px、說明兩行 | 44px高緊湊按鈕、短文案 | 留空間給模式名稱 |
| 固定360px地圖 | 可展開＋浮動面板收合 | 查看整條路線 |
| 目的地只有旗標 | 道路＋距離＋沿線資源 | 能找途中停靠點 |
| 原生直接服務 | TownPass首頁進出 | 保留宿主App導覽 |
