# 新北福利雷達

新北市福利補助資格初篩原型。這個分支只公開福利服務，根路徑 `/` 與 `/benefits` 都直接進入新北福利雷達。

## 功能

- 完整收錄新北市政府「福利補助資訊」152 筆開放資料，每筆都連回官方福利明細。
- 將其中 28 項常用方案整理為結構化深度初篩，包含低收／中低收、租屋、生育育兒、托育、身障、高齡、醫療、急難及青年就業。
- 依使用者已填身分排除明確不相關項目；未知條件不會假裝已符合。
- 對可可靠量化且初篩為「可能符合」的福利，估算一年或一次申請週期可能錯過的金額。
- 全部比對在裝置端完成，不要求姓名、身分證字號、電話或 Email。

福利雷達僅提供初篩，不是政府核定結果。所得認列、家戶人口、財產、受理狀態及實際給付仍以主管機關最新審查為準。

## 本機執行

```bash
pnpm install
pnpm dev:web
```

瀏覽器開啟 <http://localhost:5173/>。

## 更新官方福利快照

```bash
pnpm benefits:sync
```

同步程式會透過新北市資料開放平臺 API 重新產生 152 筆福利快照，保留資格說明、應備文件、申請方式、給付內容、聯絡資訊與更新日期；不使用爬蟲。

## 資料與規則邊界

- 152 是官方開放資料目前回傳筆數，不是以關鍵字二次篩選後的產品統計。
- 28 項深度規則是本專案將官方文字轉成結構化條件的範圍，其餘項目仍保留在官方候選目錄。
- 開放資料沒有一致的即時受理狀態欄位；只有官方文字明確標示全年受理、免申請或停辦時才自動標記，其他一律要求回官方明細確認。
- 本版不連接任何個人帳號，也不宣稱能取得市民戶籍、所得或財產資料。
