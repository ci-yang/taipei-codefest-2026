# App 原型 v6 驗證紀錄

日期：2026-11-07。此份記錄屬原型驗證，不是使用者研究、實機驗收或正式 Prospec verify。

## 設計審查

依 design-taste-frontend 與 emil-design-eng：公共資源地圖、手機優先，設計變化／動態／密度採 3／2／5。原型採原生 CSS，沒有冒稱官方 Material 或原生 iOS 元件。

| Before | After | Why |
|---|---|---|
| 提案側欄、版本字樣及多頁流程 | 單一全螢幕地圖 App | 開啟即使用 |
| 分散的資源設定 | 底部四類，多選任一符合 | 單手操作且保留地圖脈絡 |
| 本機回報與互助演示 | 完全移除入口及邏輯 | 依 D6 收斂主流程 |
| 卡片依路網計算距離 | 明示直線距離、來源與日期 | 對齊凍結 P0 規格 |
| 另外重建框架 | 沿用純 JS／Leaflet | 依 D7 在既有原型本體迭代 |
| 裝置無 bridge 仍期待導航 | 說明 App 限制並保留複製 | 不把失敗顯示為成功 |

圖示採 Phosphor 官方幾何；深淺色共用 tokens。主要操作至少 44px，原生 dialog 提供焦點限制與 Esc，鍵盤操作與 reduced-motion 關閉非必要動畫。沒有行銷 hero 或裝飾圖片需求，圖片生成與行銷頁 Lighthouse 指標不列為產品畫面成果。

## 自動與獨立檢查

- 新原型整合：26 項，包含定位錯誤／競態、100m 門檻、OR highlight、零筆、離線搜尋、四來源與日期、電話、方位與外部功能失敗。
- Bridge／Service Worker：24 項，包含 geo→OSM、5 秒逾時、無 bridge、離線定位、部分下載、舊包保留、scope 隔離及 Pages 首頁轉址相容。
- 搜尋：15 項，包含輸入驗證、取消／節流、逾時、來源與不外送 GPS。
- 舊路網 oracle 測試仍通過；本輪主流程不呼叫路由。
- 資料清洗：9 項，驗證來源數、座標對應、空值、電話正規化與服務標記。
- 工作區 typecheck／lint／test／build 通過；原 apps/api 14 項、apps/web 24 項測試。
- Fresh-context reviewer 未發現剩餘高／中缺陷；發現的搜尋 disabled、舊導航回覆與離線提示被覆蓋問題已修復並加入回歸案例。

## 實際瀏覽器檢查

Chrome，390×844 與 320×740：

- 全螢幕地圖、底部分類、資源卡片、來源日期與原生對話框可操作。
- 充電與 Wi-Fi 可同時選取；來源點位保留，符合者高亮。
- 本機搜尋新東陽，選取後移動目的地標記。
- 點導航／撥號均顯示「需在台北通 App 內使用」，卡片保留地址與電話可複製。
- 淺色模式可切換；320px 實測 document scrollWidth 等於 clientWidth，無水平溢出。
- 初次載入出現下載進度並完成 14 項快取。
- **停止該原型的本機 HTTP 伺服器後重載**，入口、腳本、底圖、全市資料仍能載入，分類與本機搜尋可操作。這是服務中斷驗證，沒有宣稱切斷 OS 全部網路或飛航模式。
- 此瀏覽器定位曾逾時；介面正確保留非目前位置標示，沒有用示範座標代替成功。
- 分享站複驗時，瀏覽器回傳有效位置與精度；畫面依回傳座標移動、顯示取得時間，卡片顯示相對位置的直線距離。沒有將定位寫進原型資料檔。
- 分享站發現 `index.html` 的 HTTP 308 導致離線包 partial。修正為從同 scope 首頁下載、保留兩種入口快取 key，仍拒絕轉址；補兩項 regression，包含跨 scope 回應拒絕。獨立 reviewer 以只讀方式確認安全及 fallback 邊界未被放寬。
- 修正版分享站 `57c6867d600ab5e6` 於 18:07 顯示「已快取」與儲存時間；重新載入後仍顯示完整快取，定位重新取得有效位置。這次公開環境檢查有網路，並未宣稱飛航模式驗證。
