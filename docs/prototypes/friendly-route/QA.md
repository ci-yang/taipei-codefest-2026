# 友善同行 Prototype 驗證紀錄

2026-11-07，以桌面 Chrome 與 390 × 844 viewport 驗證。這是原型測試紀錄，不是族群需求或店家現場可用性的調查。

| 項目 | 驗證與結果 |
|---|---|
| 資料真實性 | 獨立 reviewer 逐筆核對 103 家店、四旗標、地址及座標，全部與官方 CSV 相符；8,985 個 OSM 圖徵、60,698 組座標與官方 API 匯出相符。 |
| 全區與沿線篩選 | 全示範區四類任一符合共 89 店；預設沿線 250m 為 23 店。只選無障礙時預設沿線為 1 店；搜尋不明店名呈現零結果。 |
| 多目的地 | 新增第三目的地「臺北市信義運動中心」、更新路線、上移站序均可操作；未知名稱保留欄位並提示錯誤。 |
| 評論分級 | 初始零回報。以明示流程測試的本機回報依序重現「有順利回報」、「需再確認」及相反回報數量；清除後回到尚無回報。未製造真實消費紀錄。 |
| 詢問卡 | 店家抽屜可展開大字詢問卡、地址及電話；列印入口存在。未實際撥號或列印。 |
| 無快取離線 | 未下載時啟用離線示範，出現無資料提示，不能新增路線或送協助。 |
| 完整快取重開 | 完成下載後，停止此任務自行啟動的本機 HTTP 服務，再重新整理；底圖、23 間沿線店家、兩目的地路線與儲存時間仍可讀。新版 SW 修補後重測通過。 |
| 下載失敗 | 獨立 reviewer 以原始 SW 注入 quota failure 及延遲寫入；本 scope 快取清除、其他 scope 保留，頁面撤銷已下載狀態。 |
| 求助同意 | 未勾位置同意時阻擋送出；路線預設不分享，接收者只看見選定求助點。主動勾選後才看到三個路線點。 |
| 回應與終止 | 本機雙角色可回應、撤銷及測試到期；撤銷／到期後接收者不再看到地點與路線。離線時送出按鈕停用。 |
| 到期時鐘 | 獨立 reviewer 以原始程式注入逾期時間；延後 timer 不會讓過期請求重新被回應，取消狀態不復活。 |
| 手機版 | 390px 沒有水平溢出；查看路線會捲動至地圖，接收者小地圖與回應按鈕可見。 |
| 規格 | 五故事、17 情境，獨立內容審查 PASS，`prospec validate proposal` PASS；revision 1 已由 CLI freeze。Knowledge 與跨故事契約依賴保留 WARN。 |

已修正：helper 小地圖在隱藏容器初始化造成的 Canvas 錯誤、移除時殘留縮放動畫、快取部分寫入失敗仍顯示可用、逾期請求在 timer 執行前可被回應。

## 尚未宣稱通過

尚未在實體 Android／TownPass WebView 進行斷網重開測試；未接真正步行路由、公開回報後端與真人通知。瀏覽器手動離線開關是展示功能，與停止本機來源後重開的測試分開記錄。未改作業系統的 Wi-Fi 設定。
