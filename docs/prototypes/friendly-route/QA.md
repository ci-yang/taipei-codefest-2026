## 機檢與修復

`node --test docs/prototypes/tests/friendly-app-state.test.cjs docs/prototypes/tests/friendly-routing.test.cjs`：21 項通過，0 失敗。`app.js`、`sw.js`、`routing.js` 語法檢查通過。

本輪發現並修復：還原離線行程後仍編輯舊草稿、歷史遺失所選方案、計算期間舊比較可互動，以及來源停止後 SW 重新註冊失敗阻擋既存離線包恢復。修復由非作者 reviewer 複驗；最後一項另以 Chrome 停止來源重測通過。

店家與底圖沿用第一版已獨立核對的官方資料：103 家店的四旗標、地址、座標吻合原始 CSV；8,985 圖徵、60,698 座標吻合 OSM 匯出。本輪未替換該資料。
