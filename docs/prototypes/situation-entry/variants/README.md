**結果：選 B**（2026-11-08 曄：「只有B合格」）。主版（上一層的 `index.html`／`app.js`／`styles.css`）已換成 B 的完整版；這個資料夾留作設計紀錄。三個方向共用 `../situations-data.js`、`../bridge.js`，以及 `../core.js`（時段判斷、「現在這一步」挑選、來源編號、撥號串接；原本在 `shared/core.js`，主版改用後移到上一層）。

| 方向 | 網址 | 概念 |
|---|---|---|
| A 一句話引導 | `/variants/a/` | 一次只問一件事：遇到什麼事、住哪一區，接著只給一個答案：打給誰、撥號鍵、照著念的範本 |
| B 行動卡 | `/variants/b/` | 每個情境是一張卡：大字電話、範本、可勾選的準備清單，適合截圖或拿給社工看；晚上卡頭會變深色 |
| C 城市通原生 | `/variants/c/` | 照 TownPass 元件（TPAppBar、TPCard、TPButton）做，看起來像城市通內建的服務 |

## 共同規則

- 時段：平日 8:30–17:30 算上班時間（來源是希望好食堂常見問答），其他時間算晚上或假日。國定假日判斷不出來，所以每個畫面都能手動切換。
- 上班時間先給所在區的社福中心，需要時先問住哪一區（點一下就選好）；晚上或假日先給 1999。勞資情境沒有分區窗口，直接給第一支電話。
- 選了哪一區只放在頁面記憶體裡，不存 localStorage，也不送網路請求。
- 內文每條只掛一個小編號，點了才展開頁尾的「資料來源」（含查核日期）。
