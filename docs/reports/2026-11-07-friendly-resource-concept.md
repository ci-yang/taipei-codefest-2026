# 台北借一下：友善資源接力站

> 提案：把友善店家的上網與充電資源，整理成看得見使用條件、可先詢問、可離線帶走的城市補給入口。

查核日：2026-11-07。這是候選產品設計，尚未完成使用者訪談或店家合作。台北通缺少此入口是Ci提供的觀察，本輪未獨立盤點App全部功能。

## 對應「拿不到」

主對象是已有手機、缺乏可負擔網路的經濟弱勢；次對象是需要親友或實體窗口協助查詢的獨居長者。主方向是公共網路，並透過紙本交接保留實體取得資訊的管道。充電是維持連網的輔助資源。這題不主張設備補助，也不勉強涵蓋偏鄉。

需求假設：店家即使提供Wi-Fi，若民眾不知道能否免消費、如何登入、何時能用，仍可能無法取得資源。此障礙是否普遍，須訪談及試點驗證；目前不能宣稱已證明。

## 已查證的現況

- 官網已有關鍵字、店型、行政區、15項友善分類與列表／格狀呈現；抽查詳細頁已有營業時間、電話、地址與建議路線入口。不能把重新做地圖當主要差異。[地圖搜索](https://friendlystore.taipei/map/tw/pg1/3)、[抽查店家頁](https://friendlystore.taipei/store/tw/pg1/3/company/8830)
- 官方說明將Wi-Fi與廁所描述為免費提供給顧客；充電說明提供插座／USB，未明訂免費。這不等於每間店都承諾所有人免消費使用。[服務定義PDF](https://friendlystore.taipei/public/webads/29_tw_11780538300.pdf)
- 本次實抓中文CSV共993筆、23欄。按地址以臺北市或台北市開頭篩出986筆，其中626筆Wi-Fi標記為1、404筆充電標記為1，342筆兩者皆為1。這是紀錄與標記數，沒有推論即時可用家數。中文檔案更新日2026-07-20。[資料集](https://data.taipei/dataset/detail?id=d807396c-e41f-4005-be42-0160280783a1)
- 資料有名稱、地址、座標、電話、簡介、服務標籤與詳細頁連結；沒有結構化營業時間、免消費規則、即時名額、插座空位或Wi-Fi密碼。空白服務標記解讀為未標示，不武斷認定沒有服務。

## 提案流程

1. 從台北通進入，選「我要上網」「我要上網＋充電」，再選是否只找已確認免消費的資源。查詢不需要低收入資格或福利身分。
2. 依需求篩選，再以條件確認狀態與直線距離呈現候選點。清楚區分「官方名冊有標示」「店家已確認使用條件」「尚待確認」；人工確認必須有日期與紀錄來源，不能寫成即時可用。
3. 店家詳情優先呈現：需不需要消費、可使用時段、如何取得Wi-Fi登入方式、是否需自備充電線。這些是待蒐集的新資料；沒有就留待確認，提供電話及原始官方頁。
4. 產生可給店員看的詢問卡，例如「您好，我想使用Wi-Fi，請問是否需要消費？」。此為擬定介面文案，不是已發生對話；卡片不具有兌換或要求服務的權利。
5. 可儲存主選與備選地址、電話、服務條件摘要，支援已下載內容的離線閱讀；可由協助者列印紙卡，不能只有QR code。
6. 沒有符合免消費條件的店家時，另列Taipei Free公共熱點候選。公共熱點亦不承諾訊號正常或室內場域當下開放。[熱點資料](https://data.taipei/dataset/detail?id=6aa6532d-652f-4c1b-814a-4646b75407af)

## 32小時MVP

只做四個畫面：需求選擇、候選清單／簡圖、使用條件與詢問卡、離線／列印清單。核心來源只用友善店家CSV與Taipei Free。先挑一個行政區示範，以公開資料真實呈現；不爬取網站補營業時間。地圖若需要，使用MapLibre與OSM，沒有路網資料時只顯示直線距離。

建議分工：資料清理及唯讀API、前端清單／地圖、離線與列印、介面及Demo、店家條件核對與整合。沿用apps/api、apps/web、packages/shared；跨人契約與主流程選定後才開Story，現階段不修改程式。

最有說服力的試點是取得少量店家明確同意，確認免消費Wi-Fi的時段、操作方式及維護責任。這是待完成的合作工作，不能把未接洽店家寫成已加入。店家條件表可以先做簡單人工維護，首版不做完整店家會員系統。

若尚無任何店家完成核對，Demo仍可展示真實候選清單、待確認狀態、詢問卡與公共熱點備援；不得假造「免消費已確認」。若示範未來店家填報流程，測試資料需另標示為模擬資料，不混進真實地點的條件。

## 驗收與邊界

- 篩選「已確認免消費」時，不出現只有Wi-Fi標籤卻未確認消費條件的店家。
- 原始名冊與人工補充欄位保留各自來源、日期；沒有資料時顯示未知。
- 關網後可讀事先儲存的卡片；第一次使用就完全離線者仍需預載、紙卡或協助者。
- 無手機者不能靠Wi-Fi解決設備缺口；須另轉公用設備／實體服務路徑，不把充電店誤標為借手機處。
- TownPass WebView離線與列印支援須實機驗證；紙本可先由桌面協助端列印。
- 顧客使用回報只能做待查證線索，不自動改成官方認證或店家承諾；公眾回報延後至第二階段。
- 查詢不需新增資格驗證；不做優惠券、虛構預約、雲端LLM、即時空位或未驗證的步行分鐘數。

成功應量測使用條件核對率、詢問後實際取得服務的比例、沒有取得服務的原因；本輪無實測成效數字。
