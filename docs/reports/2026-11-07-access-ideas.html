01優先 · 工作量低至中

斷網也找得到

可離線的免費上網補給卡

經濟弱勢公共網路
拿不到什麼
有手機卻沒有足夠行動流量，臨時要查服務或送出申請時，缺的是能連上的入口。
取得路徑
先選行政區 → 儲存附近熱點清單 → 關網路仍可讀地址與熱點名稱 → 到場連線。
32小時 MVP
匯入 Taipei Free；用座標做直線距離排序；儲存文字清單與資料日期。無定位權限時可手選行政區。
無手機入口
適用有設備但缺流量者；服務人員可列印熱點卡供離線找路。完全沒有可連網設備者改走第2題的公用電腦入口。
Demo驗收
載入真實資料後開飛航模式，仍能讀出三個候選熱點；示範地址與來源日期。
界線與待補
沒有即時品質或訊號覆蓋資料；距離不代表走路時間。離線清單不等於全市離線地圖，也不能替使用者自動連上 Wi-Fi。
核心資料與依據D1 臺北市公眾區免費無線上網熱點資料（新版）

通過條件 關網後清單仍可讀；不顯示未查證的訊號強度或「保證可用」。

範圍：臺北市

02優先 · 工作量中

電腦借我一下

沒有電腦也能完成一次數位辦事

經濟弱勢、獨居長者公共網路、實體服務
拿不到什麼
只有手機、沒有電腦或無法負擔設備時，填表與整理文件需要可到場使用的設備。
取得路徑
選要辦的事 → 找圖書館候選館舍 → 看電腦使用規範 → 電話確認 → 列印到館卡。
32小時 MVP
圖書館開放資料＋官方公用電腦規範；只為人工核對過的示範館舍加上設備服務標記，其餘列「待確認」。
無手機入口
親友或據點人員代查並列印地址、電話與詢問清單；長者不用建立帳號。
Demo驗收
展示館舍清單，再把「有電腦待確認」與「人工已核對」分清，產生紙本到館卡。
界線與待補
館舍清單沒有電腦台數、空位與借用資格；不表示每館都有設備，也不承諾可帶回家或代辦公務。
核心資料與依據D2 臺北市立圖書館各分館暨民眾閱覽室 P1 北市圖電腦使用規定 P1a 安康閱覽室：設備證據

通過條件 不把館舍數當可用電腦數；未核對館舍不顯示設備可用。

範圍：臺北市

03條件式 · 工作量中

有設備，再上線

設備補助與公用上網資源準備包

經濟弱勢數位設備補助、實體服務
拿不到什麼
家庭缺設備或網路時，需要知道可以向誰詢問、何時申請，以及等候期間能去哪裡使用公用設備。
取得路徑
選設備需求 → 顯示社會局方案受理狀態與官方詢問入口 → 列印準備卡 → 等候期間查公用電腦，或向學校詢問借用。
32小時 MVP
以官方機關學校名冊找學校；人工整理一項已核實的年度方案，保留公告日期；表單只做準備清單。
無手機入口
可印給家長帶到學校詢問；也可從紙本聯絡卡用一般電話聯繫。
Demo驗收
示範115年度已截止的正確狀態，再提供學校電話與公用設備替代方案。
界線與待補
今年公告申請期已過；下一期日期、個別家庭資格與設備庫存待補。只有導引與準備功能，不能核定補助或假設全年受理。 學校詢問是另一路徑，並非已證實為該補助的受理窗口；建議併入第2題，不單押本題。
核心資料與依據D3 臺北市政府各機關學校聯絡資訊 D2 臺北市立圖書館各分館暨民眾閱覽室 P2 115年度弱勢家戶電腦設備補助公告

通過條件 過期方案不得出現「立即申請」；不收身分證、收入證明或學生個資。

05首選 · 工作量低至中

社福接力紙卡

沒有手機，也能把需求帶到對的窗口

經濟弱勢、獨居長者實體服務
拿不到什麼
缺手機、網路或能代查的人時，福利需求需要一個接得住的實體聯絡起點。
取得路徑
由服務人員或親友選需求與行政區 → 找社福中心 → 產生電話詢問與紙本接力卡 → 當事人帶卡洽詢。
32小時 MVP
社福中心名冊＋三類人工核對的服務說明；列印中心名稱、地址、電話與空白需求欄。只記本機勾選，不建立個案資料庫。
無手機入口

Demo驗收

官方列有諮詢與轉介服務，但合作窗口、回報結果與案件系統沒有接通。只承諾提供聯絡起點，不顯示「已轉介成功」。 紙卡如何交到沒有手機且無親友代查者手上，仍須與可協助列印的公共據點驗證；尚未建立合作。
核心資料與依據D5 臺北市社會福利服務中心 P4 社福中心服務內容

通過條件 卡片在紙上可獨立使用；未送件不能顯示已受理。

界線與待補
官方服務對象為60歲以上長者；經濟弱勢者亦須符合年齡等適用條件。共餐不一定免費；沒有每日菜單、名額或送餐路線。示範只能做到聯絡與確認準備，不能保證今天有餐。
核心資料與依據D6 臺北市老人共餐單位一覽表 P8 共餐服務說明

10條件式 · 工作量中

  • 0–4小時：選一題、核對一至兩個資料源、定義「取得下一步」；能接觸到目標使用者或一線人員時，先核對需求。
  • 4–12小時：匯入資料、清理編碼與空列，完成查詢與資料來源顯示。
  • 12–22小時：完成一條流程、電話／列印或離線出口；不擴做跨局處整合。
  • 22–28小時：用真實資料測試空結果、過期資料、拒絕定位、關網與列印。
  • 28–32小時：在實際 TownPass WebView 與手機預演，凍結 demo；整理限制與來源。

共用實作邊界

  • 既有 apps/web 呈現流程；apps/api 供唯讀名冊；packages/shared 放來源日期與資料型別。詳細契約等選題後再開 change。
  • 使用官方下載／開放API；政策頁只人工查核與連結，不建立爬蟲。
  • 優先文字清單；需要地圖才用專案核准的 MapLibre＋OSM。地址沒有座標時先按行政區查，不假造定位。
  • 不依賴 LLM 即可完成。若追加 AI，遵守裝置端推論限制，不拿模型決定福利或法律資格。
